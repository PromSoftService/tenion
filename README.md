# Tenion portal

Public product portal for MetaPlatform at `tenion.cloud`.

The portal is a dependency-free static site. Its document root is `public/`.

For a local preview, serve that directory with any static HTTP server.

## Conversion paths

- Product access links open `app.tenion.cloud`.
- Team and implementation enquiries use `mailto:info@promsoftservice.ru` until a server-side form handler is connected.
- “First start” and “Download center” stay disabled until their content is ready.

The landing contains no client-side form and does not collect personal data.
