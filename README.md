# Tenion portal

Public product portal for MetaPlatform at `tenion.cloud`.

The portal is a dependency-free static site. Its document root is `public/`.

For a local preview, serve that directory with any static HTTP server.

## Early-access form

The form is intentionally presentation-only in the first release. It does not collect or transmit user data. Connect a server-side mail handler before enabling its submit button.
